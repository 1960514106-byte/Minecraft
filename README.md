# Minecraft

一个纯浏览器、零依赖(Three.js 已内置于 `Minecraft/js/vendor`)的体素版 Minecraft。
启动:`cd Minecraft && python3 -m http.server 8123`,打开 http://localhost:8123/ 。

## 与正版(Java 版)的功能对照(Phase 10 完成时的审计)

经过 Phase 0–10 的十一轮迭代(存档版本 v17),游戏已覆盖正版的主要玩法闭环:

**世界与维度**
- 主世界:128 高、大陆度连续地形(海洋/深海/沙滩/平原/森林/桦木林/针叶林/沼泽/沙漠/雪原/丛林/蘑菇/花林/山地),河流、洞穴、峡谷、矿脉(煤/铁/金/红石/钻石/青金石/绿宝石)。
- 下界:岩浆海洞穴世界、下界要塞、灵魂沙、萤石、下界疣、远古残骸(下界合金)、自制 Boss「Nether Overlord」+ 下界之星。
- 末地:要塞(末影之眼定位、末地传送门)、黑曜石柱 + 末影水晶、末影龙(环绕/俯冲/栖息状态机、水晶回血)、出口传送门、龙蛋与制作人员名单。
- 结构:村庄(多建筑变体+铁匠铺)、地牢、废弃矿井、下界要塞、主世界要塞。

**生存玩法**
- 生命/饥饿/氧气/盔甲/经验条,床与重生点,死亡掉级(经验清零、死亡点返还部分经验球),盔甲耐久(受击磨损、破碎消失)。
- 工具/护甲六阶:木/石/铁/金/钻石/下界合金(铁砧锻造升级,保留附魔与耐久比例)。
- 合成(2x2/3x3、形状归一化+自动镜像)、熔炉、附魔台(锋利/效率/保护/耐久/力量 I–IV)、铁砧(合并/修复/锻造)、酿造台(约 10 种药水+喷溅型)、信标。
- 农业:小麦/胡萝卜/甘蔗/下界疣,骨粉催熟;树苗(橡/桦/云杉)掉落、随机生长与骨粉催树;钓鱼。
- 红石:红石线/火把(非门)/中继器/比较器/活塞与粘性活塞/侦测器/发射器/投掷器/漏斗/音符盒/红石灯/铁轨与动力铁轨。
- 生物 20+:僵尸/骷髅/苦力怕/蜘蛛/末影人/女巫/史莱姆/岩浆怪/恶魂/烈焰人/凋灵骷髅/蠹虫/僵尸猪灵、猪/牛/羊/鸡/鱿鱼/马/狼(驯服)/村民(职业+分级交易)/铁傀儡,以及两个 Boss。
- 载具与坐骑:矿车、船、马(需鞍;马铠三阶减伤,战利品箱限定)。
- 地图物品(全屏俯视地形图)、小地图、指南针、成就系统、昼夜与天气、创造模式(飞行+全物品选取器)。

**尚存的主要差距(按影响排序)**
1. 多人联机:无网络层,纯单机。
2. 世界为固定种子(1337),不支持多存档槽/自定义种子。
3. 生物群系细节:无竹林/恶地/樱花等新版群系;海洋无海底神殿/沉船;无掠夺者前哨。
4. 红石完备度:无 quasi-connectivity 等边缘时序特性、无命令方块。
5. 物品面:无附魔书/经验瓶/烟花/旗帜/地图缩放与墙挂等;药水种类约为正版一半。
6. 生物 AI 较简化:无村民繁殖/钟声机制,幻翼/悦灵/山羊等新生物缺席。
7. 维度细节:下界无群系分化(绯红/诡异森林、玄武岩三角洲);末地无外岛/末影城/鞘翅/潜影贝。
8. 渲染:无实体阴影/光影;区块高度 128(正版 384)。

以上差距均不阻断「开局 → 挖矿 → 下界 → 酿造附魔 → 要塞 → 末影龙 → 下界合金毕业」的完整通关闭环。
